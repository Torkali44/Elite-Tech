# Elite Tech Community — منصة مجتمع النخبة التقنية

منصة متكاملة لبنك الأفكار، مجتمع المواهب التقنية، استكشاف المسارات المهنية، بناء السيرة الذاتية، وإدارة طلبات التنفيذ والتوثيق.

---

## 🌟 مميزات المنصة

- **بنك الأفكار**: تصفح الأفكار التقنية، تقديم طلبات التنفيذ، نشر وتعديل الأفكار، والتعليق والمفضلة.
- **مسارات متعددة للأعضاء**:
  - **صاحب فكرة**: إضافة وإدارة الأفكار واستقبال طلبات التنفيذ من المطورين.
  - **باحث عن فكرة**: تصفح بنك الأفكار والمشاركة في تنفيذ الأفكار المتاحة.
  - **باحث عن عمل (مطور)**: منتدى التوظيف، بناء السيرة الذاتية واستخراج PDF، وتقديم طلبات العمل والتنفيذ.
- **منتدى التوظيف وبناء CV**: أداة تفاعلية لبناء السيرة الذاتية مع معاينة حية واستخراج صيغة PDF جاهزة للطباعة.
- **نظام التحقق وتوثيق الهوية (KYC)**: توثيق الهوية لضمان الموثوقية والأمان في منصات التوظيف والتنفيذ.
- **شبكة التواصل والرسائل**: صندوق رسائل وتواصل بين أعضاء المجتمع.
- **لوحة تحكم إدارية شاملة (Admin Dashboard)**:
  - متابعة ومراجعة الأفكار المنشورة وإرجاعها كمسودة أو قبولها.
  - إدارة المستخدمين وتفعيل/تعليق الحسابات وإبراز المسارات المحددة.
  - متابعة طلبات التنفيذ والتوثيق KYC.
  - عرض مؤشرات الأداء الحيوية مثل **Conversion Rate** و **متوسط SLA لـ KYC**.

---

## 🛠️ التقنيات المستخدمة

- **Framework**: Laravel 11
- **Frontend**: Blade, Alpine.js, Tailwind CSS
- **Database**: SQLite / MySQL
- **Design & Layout**: RTL كامل مع خط Cairo وتصميم متجاوب لجميع الشاشات

---

## 🚀 طريقة التشغيل المحلية

```bash
# 1. تثبيت الاعتمادات
composer install

# 2. إنشاء ملف الإعدادات
cp .env.example .env

# 3. توليد مفتاح التطبيق
php artisan key:generate

# 4. تشغيل الهجرات والبيانات المبدئية
php artisan migrate --seed

# 5. تشغيل السيرفر المحلي
php artisan serve
```

افتح المتصفح على: `http://localhost:8000`
